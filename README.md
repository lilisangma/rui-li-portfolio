# 李睿 Rui Li — 个人作品集

简洁的中文个人作品集，包含 5 个项目案例、视觉档案、教育与实习履历、能力和联系方式。

## 内容与维护

- `dist/index.html`：首页与个人信息
- `dist/app.js`：项目文字、案例图片与互动
- `dist/style.css`：响应式视觉样式
- `dist/assets/`：作品集原始页面图片、简历与完整作品集

无需安装依赖。可直接部署 `dist` 文件夹。GitHub Pages 使用 `docs` 副本发布。

设计作品与个人材料版权归李睿及相应权利人所有。项目页区分实习参与与概念探索，未虚构增长、医疗或商业验证结果。

本仓库不包含身份证、证书扫描、账户凭据或原始工作记录。
